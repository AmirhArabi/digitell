# نقشه راه پنل مدیریت --- Zitro Shop

مبنا: PRD ممیزی کد در commit `fb71e2a`، به‌روزرسانی 2026-10-13. قابلیت‌های
موجود را با موارد پیشنهادی اشتباه نگیرید.

## فاز 0 --- امنیت و آمادگی انتشار (P0)

-   [ ] تنظیم محیطی `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS` و تنظیمات
    ایمیل؛ افزودن dependency manifest نسخه‌دار.
-   [ ] حفاظت از فاکتور و پیگیری سفارش با کنترل مالکیت/توکن امن و
    محدودسازی نرخ.
-   [ ] محدودکردن اعطای `is_staff` به superuser یا مجوز اختصاصی.
-   [ ] اجرای password validators در ثبت‌نام؛ محدودسازی login/register.
-   [ ] پاک‌سازی SVG خام دسته‌بندی که با `safe` نمایش داده می‌شود.
-   [ ] تنظیم HTTPS، secure cookies، HSTS و اجرای `check --deploy`.
-   [ ] افزودن آزمون‌های regression برای کنترل‌های بالا.

## فاز 1 --- صحت سفارش و موجودی (P0)

-   [ ] تصمیم‌گیری درباره وضعیت COD؛ کد فعلی `status=paid` و
    `payment_status=pending` ثبت می‌کند.
-   [ ] کسر موجودی اتمیک و جلوگیری از overselling.
-   [ ] اعتبارسنجی quantity در تمام مسیرهای سبد و checkout.
-   [ ] جلوگیری از مصرف دوباره کوپن در درخواست‌های هم‌زمان.
-   [ ] هم‌راستاسازی گزارش درآمد با تعریف مالی وضعیت پرداخت/COD.
-   [ ] آزمون رقابت برای آخرین واحد موجودی و آخرین استفاده کوپن.

## فاز 2 --- عملیات پنل (P1)

-   [ ] هشدار سفارش پرداخت‌نشده و کوپن نزدیک انقضا؛ این هشدارها برخلاف
    ادعای roadmap فعلی، پیاده نشده‌اند.
-   [ ] پیاده‌سازی «کپی سریع محصول»؛ در سند قبلی ادعا شده اما در کد یافت
    نشده است.
-   [ ] تکمیل آزمون تیکت‌ها و مسیرهای کم‌آزمون.
-   [ ] ثبت audit log برای عملیات staff.
-   [ ] تکمیل CRUD آدرس مشتری و انتخاب آدرس در checkout.
-   [ ] پیاده‌سازی فرم تماس به‌صورت ذخیره پیام و/یا اعلان واقعی.
-   [ ] صفحه‌بندی فهرست‌های حجیم و بررسی سقف 200 ردیف موجودی.

## فاز 3 --- گزارش و عملیات (P1/P2)

-   [ ] گزارش مالی و تطبیق تسویه پس از انتخاب PSP واقعی.
-   [ ] backup/restore دیتابیس و media همراه با آزمون بازیابی.
-   [ ] ایمیل/SMS تراکنشی پس از انتخاب provider. طراحی SMS تیکتینگ
    (SMS.ir/آی‌پی‌پنل) آماده است: `docs/SMS_TICKETING_DESIGN.md`.
-   [ ] سیاست نگهداری داده و صفحه حریم خصوصی.
-   [ ] logging ساخت‌یافته و پایش خطا.

## فاز 4 --- قابلیت‌های برنامه‌ریزی‌شده (P2)

-   [ ] RBAC با Django Groups/permissions و مدیریت اپراتورها.
-   [ ] 2FA و allowlist آی‌پی در صورت نیاز.
-   [ ] صفحات ثابت قابل مدیریت.
-   [ ] هزینه ارسال بر اساس روش/منطقه.
-   [ ] کمپین ایمیل/SMS.
-   [ ] نظرات محصول و moderation.
-   [ ] علاقه‌مندی و سبد رهاشده.

## تصمیم‌های مسدودکننده

انتخاب PSP، تعریف مالی COD، مالک اعطای دسترسی staff، providerهای
ایمیل/SMS، بستر میزبانی و الزامات حریم خصوصی/نگهداری داده.

## وضعیت پایه

پنل شامل کاتالوگ، موجودی، سفارش، مشتری، کوپن، بنر، وبلاگ، تنظیمات، گزارش
و تیکت است. PRD از 35 آزمون پاس‌شده گزارش می‌دهد؛ ماژول تیکت آزمون خودکار
نداشت.
