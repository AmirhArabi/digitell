# امنیت و حریم خصوصی --- Zitro Shop

این سند بر اساس یافته‌های PRD است؛ گواهی امنیت یا جایگزین تست نفوذ نیست.

## یافته‌های امنیتی ثبت‌شده

-   **SEC-001:** password validators پیکربندی شده‌اند ولی در ثبت‌نام اجرا
    نمی‌شوند.
-   **SEC-002:** ثبت‌نام عمومی، بدون CAPTCHA/rate limit؛ قفل ورود بعد از
    تلاش‌های ناموفق وجود ندارد.
-   **SEC-003:** فاکتور و tracking عمومی‌اند؛ دانستن شماره سفارش می‌تواند
    اطلاعات سفارش را افشا کند.
-   **SEC-004:** هر staff می‌تواند کاربر دیگر را staff کند.
-   **SEC-005/006/010:** تنظیمات تولید، HTTPS، secure cookies و HSTS
    کامل/تأییدشده نیستند.
-   **SEC-007:** رسانه‌ها عمومی‌اند؛ avatar نیز در این فضای رسانه‌ای قرار
    دارد.
-   **SEC-008:** اعتبارسنجی ورودی‌ها دستی و ناهمگون است؛ quantity غیرعددی
    می‌تواند خطا دهد.
-   **SEC-009:** SVG خام دسته با `safe` در صفحه عمومی نمایش داده می‌شود.
-   **SEC-011:** سیاست حریم خصوصی، رضایت cookie و نگهداری داده مستند
    نیست.

## چک‌لیست پیش از production

-   [ ] `SECRET_KEY` از secret manager/environment و بدون fallback
    ناامن.
-   [ ] `DEBUG=False`, `ALLOWED_HOSTS` محدود، اجرای
    `manage.py check --deploy`.
-   [ ] HTTPS؛ `SESSION_COOKIE_SECURE`, `CSRF_COOKIE_SECURE`, HSTS و
    سیاست SameSite/HttpOnly.
-   [ ] rate limit برای login/register/tracking و پایش تلاش‌های ناموفق.
-   [ ] کنترل مالکیت سفارش/فاکتور و مجوز صریح برای هر عملیات staff.
-   [ ] اعطای staff فقط به superuser/نقش مجاز.
-   [ ] `validate_password()` در ثبت‌نام و آزمون سیاست رمز.
-   [ ] sanitize SVG؛ محدودیت نوع/اندازه فایل آپلودی؛ auto-escaping قالب
    حفظ شود.
-   [ ] اعتبارسنجی عدد/بازه سمت سرور و عدم اعتماد به ورودی مرورگر.
-   [ ] لاگ بدون رمز، session ID یا اطلاعات پرداخت حساس.
-   [ ] mock payment فقط محیط آزمایش باشد؛ PSP واقعی به callback امضاشده
    و verification سرور نیاز دارد.
-   [ ] سیاست حداقل‌سازی، نگهداری، دسترسی و حذف داده؛ backup رمزگذاری‌شده
    و محدود.

## فرایند توسعه امن

dependencyها pin و آسیب‌پذیری‌ها بررسی شوند؛ تغییرات auth، authorization،
قیمت، کوپن، سفارش و موجودی نیازمند code review و آزمون regression هستند.
تست نفوذ، load test و بازبینی حقوقی در ممیزی انجام نشده‌اند.
