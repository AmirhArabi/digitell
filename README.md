# فروشگاه اینترنتی زیترو (Zitro Shop)
بازطراحی و پیاده‌سازی مدرن پلتفرم فروشگاهی کالای دیجیتال زیترو با پشته **Django 6 + TailwindCSS v4 + HTMX**.

---

## 🚀 ویژگی‌های کلیدی سیستم

### ۱. معماری بک‌اند (Backend)
- **فریم‌ورک**: Django 6 با پایتون ۳.۱۴
- **اپلیکیشن‌های ماژولار**:
  - `accounts`: مدل کاربری سفارشی با پشتیبانی از ورود با شماره موبایل ایرانی (`09xxxxxxxxx`) و آدرس‌های تحویل.
  - `products`: دسته‌بندی درختی، برندها، کاتالوگ محصولات با قیمت به تومان، تخفیف، موجودی انبار، گارانتی و مشخصات فنی.
  - `cart`: سبد خرید با شناسایی کوکی سشن / کاربر و محاسبه خودکار سود مشتری از خرید.
  - `orders`: چرخه کامل سفارشات با کدهای منحصر‌به‌فرد (`ZT-XXXXXX`) و رهگیری آنلاین.
  - `home`: صفحه نخست منطبق بر زیترو، بنرهای تبلیغاتی، پیشنهادات شگفت‌انگیز و تنظیمات سراسری.
  - `blog`: بخش مقالات و اخبار تکنولوژی و گجت‌ها.
  - `dashboard`: پنل مدیریت اختصاصی و سفارشی برای فروشندگان.

### ۲. رابط کاربری و تعاملات پویا (Frontend & HTMX)
- **جهت‌گیری کامل راست‌چین (RTL)** و فونت وزیرمتن (Vazirmatn).
- **TailwindCSS v4**: استایل‌دهی سریع با پالت برند زیترو (`#1d4ed8`، `#f97316`).
- **HTMX بدون ریفرش صفحه**:
  - جستجوی زنده (Live Search) با دی‌بانس ۳۰۰ میلی‌ثانیه.
  - فیلتر و مرتب‌سازی محصولات در صفحه فروشگاه بدون بارگذاری مجدد کل صفحه.
  - افزودن، کم/زیاد کردن تعداد و حذف کالا در سبد خرید با به‌روزرسانی هم‌زمان بج (`#cart-badge`) و جدول هزینه‌ها.
  - تزریق خودکار توکن امنیت `csrftoken` در تمامی درخواست‌های ایجکسی HTMX.

### ۳. شبیه‌ساز پرداخت آنلاین و رهگیری
- **درگاه پرداخت آزمایشی شاپرک**: شبیه‌سازی کامل فرآیند خرید اینترنتی با ارائه شماره تراکنش معتبر (`TRX-XXXXXXXX`).
- **صفحه فاکتور و رسید موفقیت‌آمیز**.
- **رهگیری سفارشات**: امکان پیگیری وضعیت مرسوله (در حال پردازش، ارسال شده، تحویل داده شده) با شماره سفارش یا موبایل.

### ۴. پنل مدیریت سفارشی فروشگاه (`/dashboard/`)
- نمایش شاخص‌های عملکرد (KPI) کل فروش، تعداد سفارش‌ها و مشتریان.
- هشدار کسری موجودی کالاها در انبار.
- مدیریت کامل کاتالوگ کالاها (ثبت، ویرایش و حذف).
- کنترل وضعیت سفارش‌ها و مرسوله‌ها.
- ویرایش شماره تماس، ایمیل و ساعات کاری فروشگاه.

## 🛠️ دستورات راه‌اندازی و اجرا

### ۱. اجرای سرور توسعه جنگو
```bash
python manage.py runserver
```
آدرس دسترسی در مرورگر: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

### ۲. کامپایل استایل‌های Tailwind CSS (در صورت نیاز به تغییرات ظاهری)
```bash
npm run build:css
```
یا حالت مانیتورینگ زنده:
```bash
npm run watch:css
```

### ۳. اجرای تست‌های خودکار
```bash
python manage.py test
```
