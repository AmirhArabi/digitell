# فروشگاه اینترنتی زیترو (Zitro Shop)
بازطراحی و پیاده‌سازی مدرن پلتفرم فروشگاهی کالای دیجیتال زیترو با پشته **Django 6 + TailwindCSS v4 + HTMX**.

---

## 🚀 ویژگی‌های کلیدی سیستم

### ۱. معماری بک‌اند (Backend)
- **فریم‌ورک**: Django 6 با پایتون ۳.۱۴
- **اپلیکیشن‌های ماژولار**:
  - `accounts`: مدل کاربری سفارشی با پشتیبانی از ورود با شماره موبایل ایرانی (`09xxxxxxxxx`) و آدرس‌های تحویل.
  - `products`: دسته‌بندی درختی، برندها، کاتالوگ محصولات با قیمت به تومان، تخفیف، موجودی انبار، گارانتی و مشخصات فنی.
  - `cart`: سبد خرید با شناسایی کوکی سشن / کاربر و محاسبه خودکار سود مشتری از خرید.
  - `orders`: چرخه کامل سفارشات با کدهای منحصر‌به‌فرد (`ZT-XXXXXX`) و رهگیری آنلاین.
  - `home`: صفحه نخست منطبق بر زیترو، بنرهای تبلیغاتی، پیشنهادات شگفت‌انگیز و تنظیمات سراسری.
  - `blog`: بخش مقالات و اخبار تکنولوژی و گجت‌ها.
  - `dashboard`: پنل مدیریت اختصاصی و سفارشی برای فروشندگان.

### ۲. رابط کاربری و تعاملات پویا (Frontend & HTMX)
- **جهت‌گیری کامل راست‌چین (RTL)** و فونت وزیرمتن (Vazirmatn).
- **TailwindCSS v4**: استایل‌دهی سریع با پالت برند زیترو (`#1d4ed8`، `#f97316`).
- **HTMX بدون ریفرش صفحه**:
  - جستجوی زنده (Live Search) با دی‌بانس ۳۰۰ میلی‌ثانیه.
  - فیلتر و مرتب‌سازی محصولات در صفحه فروشگاه بدون بارگذاری مجدد کل صفحه.
  - افزودن، کم/زیاد کردن تعداد و حذف کالا در سبد خرید با به‌روزرسانی هم‌زمان بج (`#cart-badge`) و جدول هزینه‌ها.
  - تزریق خودکار توکن امنیت `csrftoken` در تمامی درخواست‌های ایجکسی HTMX.

### ۳. شبیه‌ساز پرداخت آنلاین و رهگیری
- **درگاه پرداخت آزمایشی شاپرک**: شبیه‌سازی کامل فرآیند خرید اینترنتی با ارائه شماره تراکنش معتبر (`TRX-XXXXXXXX`).
- **صفحه فاکتور و رسید موفقیت‌آمیز**.
- **رهگیری سفارشات**: امکان پیگیری وضعیت مرسوله (در حال پردازش، ارسال شده، تحویل داده شده) با شماره سفارش یا موبایل.

### ۴. پنل مدیریت سفارشی فروشگاه (`/dashboard/`)
فهرست کامل قابلیت‌ها و پلن اولویت‌بندی در سند [نقشه راه پنل ادمین](docs/ROADMAP_ADMIN_PANEL.md) آمده است.

**داشبورد و گزارش‌ها**
- شاخص‌های عملکرد (KPI): فروش کل/امروز/هفته، سفارش‌های در انتظار، محصولات فعال، مشتریان، هشدار انبار.
- صفحه **گزارشات**: KPI فروش/سفارش/محصول/موجودی/مشتری با مقایسه درصدی بازه قبل، ۸ نمودار
  (روند فروش، سهم دسته‌ها، سبد خرید، وضعیت سفارش‌ها، سفارش‌های روزانه، فروش مشتریان،
  پراکندگی حاشیه سود و ارزش موجودی)، جداول محصولات پرفروش/کم‌فروش، گزارش موجودی انبار
  (موجودی فعلی، ارزش، آماده ارسال، رزرو شده، کالاهای کم‌فروش/مرده)، جدول مشتریان برتر،
  فیلتر بازه زمانی/دسته/برند و سه خروجی CSV (کالاها/انبار/مشتریان).
- میان‌بُرهای دسترسی سریع و پرفروش‌ترین کالاها.

**مدیریت کاتالوگ**
- محصولات: فیلتر پیشرفته (دسته/برند/وضعیت/موجودی)، مرتب‌سازی، صفحه‌بندی و عملیات گروهی
  (فعال/غیرفعال، برگزیده، شگفت‌انگیز، حذف گروهی).
- فرم کامل محصول: عنوان فارسی/لاتین، SKU، گارانتی، امتیاز، آستانه هشدار موجودی،
  آپلود چندتصویری با تعیین تصویر اصلی، گالری با حذف/تعیین تصویر اصلی، ردیف‌های پویای مشخصات فنی
  و پیشنهاد خودکار ویژگی‌های هر دسته.
- دسته‌بندی درختی (والد/فرزند)، آیکون SVG، تصویر، ترتیب و فعال/غیرفعال‌سازی.
- برندها با لوگو، نام لاتین و تعداد کالا.
- ویژگی‌ها (Attributes): تعریف ویژگی‌های متن/عدد/انتخابی/بله‌و‌خیر با واحد، قابل استفاده در فرم محصول.
- مدیریت انبار: ویرایش گروهی موجودی و حد هشدار + ارزش ریالی انبار.

**فروش و مشتریان**
- سفارش‌ها: فیلتر وضعیت/پرداخت/تاریخ، جستجو، صفحه جزئیات و فاکتور قابل چاپ، ثبت کد رهگیری مرسوله،
  یادداشت داخلی و خروجی CSV سازگار با Excel فارسی.
- مشتریان (بازطراحی‌شده): نوار KPI سریع، سگمنتبندی (VIP/فعال/جدید/غیرفعال) با فیلتر یک‌کلیکه،
  جدول جمع‌شونده با نشان وضعیت، نوار پیشرفت سهم فروش، ترتیب‌دهی ستونی، ریزه‌حای پراکندگی
  خرید و برچسب‌های وضعیت سفارش — به‌همراه پرونده مشتری با کارت پروفایل، نوار فاکتور
  سفارش (کل/پرداخت‌شده/سود)، نمودار روند خرید، آیینه وضعیت سفارش‌ها، تایم‌لاین کالاها
  و خلاصه سبد خرید رهاشده.
- کدهای تخفیف: درصدی/مبلغی، سقف تخفیف، حداقل سفارش، سقف استفاده و بازه اعتبار +
  اعمال کد در صفحه تسویه حساب.

**محتوای فروشگاه**
- بنرها و اسلایدرها در چهار جایگاه با ترتیب‌دهی، فعال/غیرفعال‌سازی و مدیریت تصویر.
- مقالات و دسته‌های وبلاگ با وضعیت پیش‌نویس/منتشرشده و تصویر شاخص.
- تنظیمات فروشگاه: اطلاعات پایه، شبکه‌های اجتماعی، هزینه ارسال، آستانه ارسال رایگان،
  درباره فروشگاه و متن پاورقی.

## 🛠️ دستورات راه‌اندازی و اجرا

### ۱. اجرای سرور توسعه جنگو
```bash
python manage.py runserver
```
آدرس دسترسی در مرورگر: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

### ۲. کامپایل استایل‌های Tailwind CSS (در صورت نیاز به تغییرات ظاهری)
```bash
npm run build:css
```
یا حالت مانیتورینگ زنده:
```bash
npm run watch:css
```

### ۳. اجرای تست‌های خودکار
```bash
python manage.py test
```
